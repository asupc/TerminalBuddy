# TerminalBuddy v1.2.0 功能更新清单

> 发布日期：2026-07-15

---

## 🎨 设计系统

- **设计系统全局刷新**：CSS 令牌化色板重构，统一色彩变量体系，支持亮/暗双主题无缝切换
- **图标组件化**：全面迁移至 lucide-react 图标库（2000+ 图标），替换散落的内联 SVG，图标风格统一
- **无障碍标注**：交互元素补充 `aria-label` 与 focus 态，提升屏幕阅读器兼容性与键盘导航体验

## 🖥️ 终端体验

- **Claude Hook 终端内决策交互**：支持在 xterm 终端内直接确认/拒绝 Claude Code 的文件操作决策，无需切换窗口
- **决议通道重构为枚举**：决策通知通道（原生通知 → 终端 → 两者）统一为枚举模型，消除魔法字符串
- **新建终端增强**：`startTerminal` 支持携带自定义标签名；右键菜单"新建终端"自动继承原会话名称
- **启动性能优化**：PTY 改为异步创建 + 标签恢复并发化 + 批量恢复期间跳过 `localStorage` 写入，启动耗时大幅降低
- **MSTSC 凭据安全升级**：凭据存储从 `cmdkey.exe` 命令行工具迁移至 Win32 `CredWriteW` API，凭据不再暴露在进程命令行中

## 🔔 通知与机器人

- **Claude Code 桌面通知体系**：新增 Toast 桌面通知，决策通知与完成通知独立拆分，支持可配置延迟发送
- **多平台机器人推送**：新增机器人通知功能，支持飞书、钉钉平台消息推送，可与终端事件绑定
- **飞书长连接 WebSocket**：飞书通道从 HTTP 轮询升级为 WebSocket 长连接模式，消息延迟显著降低
- **扫码授权流程**：飞书/钉钉支持二维码 + 设备码 OAuth 授权，扫码成功后凭证自动保存，无需手动确认
- **任务完成检测优化**（3 轮迭代）：修复子代理状态误匹配、增加 spinner 帧识别、引入提示符隐藏追踪与忙碌证据校验

## 🧭 VSCode Activity Bar 风格侧边栏

- 全新侧边栏架构：文件树、配置列表、Git 面板整合至垂直 Activity Bar，图标切换交互
- 配置导航栏（ConfigNav）与文件树导航栏（FileNav）独立可切换
- Git 面板新增历史记录树形展示，支持"加载更多"分页

## ⚙️ 设置体验重构

- **设置页面全新重构**：8 大设置分区重新组织，交互逻辑清晰化
- **设置页自动保存**：所有配置修改即时自动持久化，移除"保存"按钮
- **VSCode 模式**：新增 VSCode 风格终端布局，活动栏 + 面板的经典 IDE 布局
- **F2 重命名**：选项卡支持 F2 快捷键重命名，纵向/横向选项卡均生效
- **快捷键作用域限制**：F2 快捷键限制在配置面板/标签导航激活时生效，避免全局冲突

## 🔧 Git 集成增强

- Git 信息缓存至内存复用，避免终端频繁读取磁盘
- Git 历史记录以树形结构展示，支持增量加载更多提交记录

## 🐛 修复

- 修复 xterm.js 光标渲染异常问题
- 修复终端右键粘贴重复触发两次的问题
- 修复 Git Push 时 commit 记录不显示的问题
- 多项 UI 细节调整与图标尺寸优化
