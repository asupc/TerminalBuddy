## [1.5.0] - 2026-09-23

### 🔐 Web 安全与会话隔离
- **会话隔离与权限矩阵**：新增统一权限矩阵（`TerminalActor` × `TerminalAction` × `TerminalOwner`），`TerminalService::authorize` 统一鉴权；默认隔离模式下 Web 端看不到也连不上 PC 终端（列表隐藏 + WS 握手 403），PC 端对 Web 终端只读
- **WS 鉴权前置与复检**：WebSocket 升级前完成鉴权，每条消息及每 5 秒复检权限，共享开关关闭后约 5 秒切断在途连接；Web 永远不能关闭 PC 终端
- **登录暴力破解防护**：按 IP 失败计数 + 指数封禁退避，bcrypt 校验并发限流（429 + `Retry-After`）
- **Web SPA 适配**：前端适配会话隔离设置与权限变更

### 🛡️ 终端修复
- **粘贴行尾统一为 CR**：修复 ConPTY 把 LF 当 Ctrl+Enter、pi 等 kitty 协议 TUI 下多行粘贴乱码与逐行误提交
- **debug 日志增强**：日志增加日期与退出码；VS Code 终端宿主改用专属进程名，避免被误杀
- 修复启动 bug

### ⚙️ 设置与参数预设
- 补上 `settingsVersion` 实现，修复设置变更时报错与标签栏不刷新
- 参数预设新增启用 / 禁用开关，禁用后不再出现在右键启动菜单

### ⌨️ 快捷键
- 修复全局快捷键注册始终提示被占用的问题

### 🎨 外观与 UI
- 应用图标焕新：全新「双窗结伴」Logo
- 修复皮肤背景色色块问题并完成皮肤适配
- 修复弹窗打开时闪烁（CSS 动画不连续 + `useEffect` 死循环）

### 📚 文档与工程
- 更新架构说明与完整使用指南，新增 BUG 审计清单与 invoke 覆盖校验脚本
- 忽略 `.codex` 与 `.playwright-mcp` 目录

## [1.3.0] - 2026-07-20

### 🚀 启动参数预设体系（ExtraParamsPreset）
- **后端 REST 接口上线**：新增启动参数预设的 CRUD REST 接口；终端实例挂载 `tag` 字段，用于在会话列表中标识当前生效的预设
- **桌面端交互增强**：预设选择支持按当前命令行做模糊匹配过滤；Dialog 采用受控离场动画，避免快速关闭时动画跳变
- **跨端字段对齐**：`terminal-created` 事件补齐 `extraParamTag` / `extraParamColor`，保证 Web 端能拿到与 PC 一致的预设信息
- **可视化展示**：预设支持 tag 颜色配置，并在 tab 上以色块形式展示，一眼区分不同预设下启动的会话

### 🌐 Web 端能力补齐
- **Nav 树形重构**：复用 PC 端 `TreeView` 类名，新增会话右键菜单（关闭、断开、复制 ID 等）；Terminal 主题色随当前 profile 自动切换
- **双 tab 布局**：Nav 重构为"会话 / 连接"双 tab；新增 profile 属性面板与会话分组的折叠/关闭入口，Profile 字段与后端对齐
- **命令历史共享**：后端新增命令历史 REST 接口，与 PC 端 `ClientData` 共享同一份历史；Web 端接入命令历史与终端主题色类型
- **细节优化**：`handleSessionMenuAction` 补齐 `setView` 的 `loadingMode` 字段；`InputBar` 快捷键面板重排，方向键靠前；自定义 Host 改为内联输入
- **稳定性**：修复网页端启动乱码问题

### 🔤 分屏终端字号可配置
- **设置项上线**：`AppSettings` 新增分屏终端三档字号字段（off / 2x1 / 2x2）
- **行为页配置入口**：设置 → 行为页新增终端字号配置，可在关闭、紧凑、舒适三档间切换
- **响应式生效**：分屏/单屏字号改读设置并响应 `app-settings-changed` 事件，切换即生效无需重启
- **边界兜底**：字号输入为空时回退到行默认值（对齐 spec §6）

### ⚡ 终端性能与稳定性
- **占位会话机制**：添加启动中占位会话，避免 PTY 创建过程中的页签跳变与闪烁
- **WebGL 延迟挂载**：WebGL 渲染器改为按需延迟挂载，减少新建页签时的掉帧
- **批量关闭优化**：批量关闭终端时合并状态更新次数，明显改善关闭卡顿
- **编码稳定性**：修复终端偶现乱码问题

### 🤖 机器人与 Hook 体系
- **微信 ClawBot 机器人**：新增微信 ClawBot 机器人支持，与现有飞书/钉钉通道并列
- **Hook 协议迁移**：所有 Hook 全部迁移为 HTTP 模式，统一调用方式，便于跨平台集成

### 🛠️ 文件模块与 UI
- **多项目文件管理**：文件模块支持挂载多个项目根目录，方便在多个代码库间切换
- **重构文件管理**：统一文件浏览/书签/拖拽的交互路径，整理入口
- **弹框统一**：统一全局弹框组件，调整断点与字号，优化手机端访问体验
- **配置编辑优化**：配置编辑对话框字段顺序调整；`GroupCascader` 支持失焦提交，避免误触
- **细节修复**：修复切换黑白主题输入框背景不适配、分屏切换显示异常、Web 管理面板手机端布局错位等多项 UI 问题

### 🔄 兼容性
- **数据存储**：沿用 v1.2.0 的 `%APPDATA%/TerminalBuddy/` 目录结构，无需手动迁移
- **Web API**：Web API 与桌面端会话隔离策略保持不变（`webApiShareSessions` 默认 false）
- **配置文件**：v1.2.0 的 `settings.json` / `Profiles/*.json` 可直接被 v1.3.0 加载

## [1.0.0] - 2026-06-23

### 🎉 首个正式版本发布

TerminalBuddy 是一个基于 Tauri 2 + React 18 + Rust 构建的现代化 Windows 桌面终端模拟器。

### ✨ 新增功能

#### 🔧 多终端类型支持
- PowerShell 终端
- CMD 命令提示符
- SSH 远程终端连接
- Docker 容器管理
- Kubernetes (K8s) 集群操作
- 远程桌面 (MSTSC) 连接

#### 📁 配置文件管理
- 创建、编辑、复制、删除终端配置文件
- 自定义启动路径、启动命令、环境变量
- 配置专属颜色标签和图标
- 层级分组系统，支持多级级联选择器

#### 🗂️ 标签页界面
- 垂直侧边栏或水平标签栏双模式
- 标签页分组与递归折叠
- 颜色标签与呼吸灯效果
- 拖拽排序支持
- 保存和恢复标签页布局

#### 🖥️ 分屏布局
- 终端面板分割支持
- 灵活调整面板大小
- 工作区保存与恢复

#### 🌐 远程访问能力
- **SSH 远程文件管理器**
  - 面包屑导航
  - 上传/下载文件
  - 重命名、复制、移动
  - 修改文件权限 (chmod)
  - 删除文件/目录
  - 传输进度实时显示

- **服务器监控面板**
  - CPU 使用率实时监控
  - 内存和交换分区使用情况
  - 磁盘空间占用
  - 网络上传/下载速度
  - 系统运行时间

- **Web 远程访问**
  - 内置 HTTP/WebSocket 服务器

  - 移动端友好输入栏
  - 会话隔离与权限控制

#### 📝 开发辅助工具
- **智能命令补全**
  - 基于命令模板的自动建议
  - 基于历史记录的智能推荐
  - 模糊匹配算法

- **命令模板库**

  - 网络、进程、文件、系统、Git、Docker、Python、Node.js、.NET、PowerShell
  - 支持自定义模板

- **命令历史**

  - 全文搜索历史记录
  - 备注功能

- **剪贴板集成**
  - 文件路径粘贴支持
  - 右键粘贴
  - 智能检测粘贴内容类型

#### 🎨 界面与主题
- **主题系统**
  - 8 款内置主题
  - 自定义 16 色 ANSI 调色板编辑器
  - 深色/浅色/跟随系统模式

  - Ctrl+F 快速搜索
  - 高亮显示匹配结果

- **Web 前端**: React 18 + Zustand 5 + xterm.js + axios
- **编辑器**: Monaco Editor
- **构建工具**: Vite 8 + NSIS 安装包

## [1.2.0] - 2026-07-15

### 🎨 设计系统
- **设计系统全局刷新**：CSS 令牌化色板重构，统一色彩变量体系，支持亮/暗双主题无缝切换
- **图标组件化**：全面迁移至 lucide-react 图标库（2000+ 图标），替换散落的内联 SVG，图标风格统一
- **无障碍标注**：交互元素补充 `aria-label` 与 focus 态，提升屏幕阅读器兼容性与键盘导航体验

### 🖥️ 终端体验
- **Claude Hook 终端内决策交互**：支持在 xterm 终端内直接确认/拒绝 Claude Code 的文件操作决策，无需切换窗口
- **决议通道重构为枚举**：决策通知通道（原生通知 → 终端 → 两者）统一为枚举模型，消除魔法字符串
- **新建终端增强**：`startTerminal` 支持携带自定义标签名；右键菜单"新建终端"自动继承原会话名称
- **启动性能优化**：PTY 改为异步创建 + 标签恢复并发化 + 批量恢复期间跳过 `localStorage` 写入，启动耗时大幅降低
- **MSTSC 凭据安全升级**：凭据存储从 `cmdkey.exe` 命令行工具迁移至 Win32 `CredWriteW` API，凭据不再暴露在进程命令行中

### 🔔 通知与机器人
- **Claude Code 桌面通知体系**：新增 Toast 桌面通知，决策通知与完成通知独立拆分，支持可配置延迟发送
- **多平台机器人推送**：新增机器人通知功能，支持飞书、钉钉平台消息推送，可与终端事件绑定
- **飞书长连接 WebSocket**：飞书通道从 HTTP 轮询升级为 WebSocket 长连接模式，消息延迟显著降低
- **扫码授权流程**：飞书/钉钉支持二维码 + 设备码 OAuth 授权，扫码成功后凭证自动保存，无需手动确认
- **任务完成检测优化**（3 轮迭代）：修复子代理状态误匹配、增加 spinner 帧识别、引入提示符隐藏追踪与忙碌证据校验

### 🧭 VSCode Activity Bar 风格侧边栏
- 全新侧边栏架构：文件树、配置列表、Git 面板整合至垂直 Activity Bar，图标切换交互
- 配置导航栏（ConfigNav）与文件树导航栏（FileNav）独立可切换
- Git 面板新增历史记录树形展示，支持"加载更多"分页

### ⚙️ 设置体验重构
- **设置页面全新重构**：8 大设置分区重新组织，交互逻辑清晰化
- **设置页自动保存**：所有配置修改即时自动持久化，移除"保存"按钮
- **VSCode 模式**：新增 VSCode 风格终端布局，活动栏 + 面板的经典 IDE 布局
- **F2 重命名**：选项卡支持 F2 快捷键重命名，纵向/横向选项卡均生效
- **快捷键作用域限制**：F2 快捷键限制在配置面板/标签导航激活时生效，避免全局冲突

### 🔧 Git 集成增强
- Git 信息缓存至内存复用，避免终端频繁读取磁盘
- Git 历史记录以树形结构展示，支持增量加载更多提交记录

### 🐛 修复
- 修复 xterm.js 光标渲染异常问题
- 修复终端右键粘贴重复触发两次的问题
- 修复 Git Push 时 commit 记录不显示的问题
- 多项 UI 细节调整与图标尺寸优化
