### 2. 版本配置系统

#### 统一版本配置文件
- **文件**: `src/version.ts`
- **用途**: 集中管理前端应用版本号
- **优点**:
  - 单一版本源，易于维护
  - 所有前端组件共享同一版本号
  - 避免硬编码和版本不一致

**示例代码**:
```typescript
// src/version.ts
export const APP_VERSION = '1.0.0';
```

**使用方式**:
```typescript
import { APP_VERSION } from '../version';

// 在组件中使用
<span>v{APP_VERSION}</span>
```

## 🎨 UI/UX 设计

### 视觉设计原则
1. **简洁性**: 版本标签不干扰主要功能
2. **一致性**: 与现有 UI 风格保持一致
3. **可访问性**: 清晰的视觉层次和对比度
4. **响应式**: 适配不同窗口大小

### 交互设计
1. **标题栏版本标签**: 静态显示，无交互
2. **关于按钮**: 点击打开对话框
3. **关于对话框**: 
   - 点击遮罩层关闭
   - 点击关闭按钮关闭
   - ESC 键关闭（可扩展）
   - 防止点击内容区域关闭

### 颜色方案
- 版本标签使用 `--bg-tertiary` 背景色
- 版本文字使用 `--text-tertiary` 颜色
- 链接悬停使用 `--accent-color` 强调色

## 🔧 技术实现细节

### React 组件架构
```
App
└── TitleBar
    ├── 版本标签 (v1.0.0)
    ├── 关于按钮 (ℹ)
    └── AboutDialog (条件渲染)
        ├── Logo + 标题
        ├── 功能介绍
        ├── 技术栈
        └── 相关链接
```

### 状态管理
- **TitleBar 组件**:
  - `showAboutDialog`: 控制对话框显示/隐藏
  - 版本号使用常量，从 `version.ts` 导入

- **AboutDialog 组件**:
  - 无状态组件，版本号通过 props 或直接导入

### 样式实现
- 使用 CSS 自定义属性（变量）
- 支持深色/浅色主题
- Flexbox 布局
- CSS 动画（淡入、滑入）
