# TerminalBuddy v1.4.1 功能更新清单

> 发布日期：2026-08-20

---

## ⚠️ 重要变更

### 🗑️ 移除 AI 交付编排子系统

v1.4.0 引入的 AI 交付编排子系统（DAG 任务、Agent 派发、合并、决策、产物归档等）在 v1.4.1 中**完整移除**。原因：体验链路依赖外部 CLI/工作流代理，落地成本与稳定性不匹配核心场景，移除后回归"终端 + 连接 + 配置"主线。

移除范围：

- **Rust 后端**：`ai_delivery_*` 服务/命令/模型、Web handler 模块、`database_service` 中 `ai_entities` 建表/迁移/CRUD、清空 `lib.rs` 的 AI 命令注册与 setup 恢复逻辑
- **桌面前端**：删除 `ai-delivery` 窗口挂载、通知监听、悬浮按钮、终端过滤、AI 相关 invoke 封装与设置项
- **Web SPA**：删除 `AiDelivery` 页面、接口封装、路由与导航
- **机器人通道**：剥离 AI 派发交叉点（保留通道适配器、人决策主键修复）
- **文档**：从 README、`version.json`、`CLAUDE.md` 清理 AI 交付相关说明
- **编译产物**：删除独立窗口配置/授权、验证脚本、演示页与旧文档

迁移说明：

- 升级前无需手动清理；`%APPDATA%/TerminalBuddy/ai_delivery/` 目录及旧 SQLite 文件保留在磁盘上不再被读写，可按需手动删除
- Web API 会话隔离策略、会话所有权模型保持不变

## ⌨️ 快捷键系统（重磅新功能）

v1.4.1 引入统一的快捷键系统，覆盖应用内快捷键录制、全局快捷键、面板式唤起与分发。

### 核心能力

- **统一存储**：所有快捷键以 `hotkeys` 映射方式落到 `settings.json`，前端启动时按映射初始化
- **核心分发服务**：中央分发器统一处理按键，规避 React 监听与 xterm 消费冲突
- **应用快捷键**：`新建终端`、`closeTab` 等核心动作接入分发器，贴近标签栏的"执行中确认"与"特殊页签守卫"语义
- **全局快捷键**：接入 `tauri-plugin-global-shortcut`（Rust 插件 + 前端依赖），支持「后台唤起主窗口」等系统级快捷键
- **终端放行**：xterm 焦点下自动放行应用快捷键到全局分发器，避免拦截终端原生组合键
- **新建终端动作**：App 启动时挂载分发器并接入新建终端动作

### 设置与录制

- **设置页快捷键分区**：从行为设置拆出独立的快捷键分区，每个动作一行（动作名 + 录制按钮 + 描述）
- **录制组件** `HotkeyRecorder`：点击按钮按下组合键即可录制，按 `Esc` 取消
- **重复提示**：与其它动作当前生效键重复时给出提示，不阻止保存
- **操作提示**：录制操作补充提示文案（"全局 / 后台也可用"）
- **面板式唤起**：快捷键按下后弹出搜索式面板，按关键字筛选动作并直接执行

### 文档

- 新增 **快捷键系统设计 spec**（`docs/superpowers/specs/`）与 **实施计划**，覆盖动作清单、存储结构、分发协议、录制与冲突处理

## 🎨 外观与皮肤

- **UI 样式切换**：设置页新增 UI 样式（默认 / 侧边栏-VS Code 风格），选项卡、文件、配置、设置入口集中到左侧
- **终端跟随应用主题**：开启后终端配色随应用主题切换（浅色模式→浅色底）；连接配置里单独选了其他配色的不受影响
- **呼吸灯颜色模式**：新增呼吸灯颜色模式配置（设置 → 外观）
- **皮肤功能完善**：新增皮肤能力并连续适配修复（默认 / 浅色 / 暗色等），覆盖 xterm 调色板、连接预览、设置面板、Profile 头像色等场景

## 🚀 启动参数管理

- **设置页新增启动参数管理**：配置维度的额外参数（"`-X`、`-i`、`--script`" 等）独立管理，支持新增 / 编辑 / 删除
- **拖拽排序**：启动参数列表支持拖拽排序，按显示顺序依次拼接到启动命令
- **终端记录额外参数快照**：每个终端会话保存创建时使用的额外参数快照（保证后续编辑不影响已开终端的可复现性）
- **Web 端与 PC 端复用**：Web 端与 PC 端「以此配置新建终端」复用额外参数快照，跨端一致
- **追加参数修改**：补充参数编辑、删除时的状态同步与空值校验

## 🧱 模块重构

v1.4.1 把过去积累的"巨石"模块按层拆开，删除大量死代码与重复实现。

### 后端 Rust

- **`git` 模块拆分**：解析层移入 `git_parse.rs`，合并执行层重复，删除死代码
- **`terminal` 模块拆分**：公共创建路径提取到独立模块；`mstsc` 与 Claude 会话发现独立成模块
- **`bot` 模块拆分**：通道适配器移入 `services/bot_channel.rs`；抽 `build_decision_binding`
- **`claude_hook_service`** 拆两模块：`settings` 安装/修复/卸载独立成模块；`answer_card` 消重
- **`ai_usage` 按厂商拆目录**：每个厂商独立子目录 + SSH 传输独立模块；`lib.rs` 收口为引导函数
- **`bot` 决策主键冲突修复**：cancel 占位改用 sentinel channel，批量导入改 `ON CONFLICT` 覆盖

### 前端

- **`tauri.ts` 按域拆为 `services/tauri/` 目录**：调用方按域（profile / terminal / settings / fs / ...）引用，删除 16 个死导出
- **`appStore.ts` 拆 6 个 Zustand 切片**：按域拆分状态，删除 `Workspace` / `TransferPanel` 等死状态
- **`TerminalInstance` 拆 hooks**：PTY 尺寸/拖放独立成 hooks，粘贴级联收敛到单一入口
- **`TabNav` 拆三子组件 + `App.tsx` 抽自定义 hooks**：抽出 `sessionRestore` / `launchSession` / `useExitConfirm` 等独立单元，删除标签栏死搜索框

### 设置面板拆分

- **`BehaviorSettings`** 拆出 **外观设置**（`AppearanceSettings`）与 **快捷键设置**（`HotkeySettings`）两个新组件，分别承载 UI 样式 / 终端跟随主题 / 快捷键录制
- **`SettingsPage`** 接入新分区路由

## 🛠️ 修复与稳定性

- **`closeTab` 与标签栏分支对齐**：执行器对齐"编辑器脏页签确认"与"特殊页签守卫"，避免关闭未保存或系统页签
- **git 锁未释放**：修复 Git 命令在异常路径下未释放锁导致的死锁
- **窗口 resize**：内部调整窗口大小时终端 PTY 同步 resize
- **配置导航排序按钮**：修复按钮点击无反应（事件冒泡到根容器被 `closeContextMenu` 立即关闭）
- **WebView2 性能**：禁用 `msWebOOUI` / `msPdfOOUI` / `msSmartScreenProtection` / `CalculateNativeWinOcclusion` 等特性，减少遮挡计算开销
- **皮肤适配**：连续修复浅色 / 暗色模式下组件配色、连接配置、设置面板等显示异常
- **关闭快捷键与脏页签**：执行器在脏页签场景下走"确认关闭"路径，避免误关正在编辑中的标签

## 📌 升级建议

- 从 v1.4.0 / v1.3.x 升级可直接覆盖安装，无需先卸载
- 删除 AI 交付子系统后，**全部相关配置项、命令、入口、菜单、文件将不再生效**，无需手动清理
- 如果计划长期保留 AI 交付相关数据，建议覆盖安装前手动备份 `%APPDATA%/TerminalBuddy/ai_delivery/` 目录
- 启用全局快捷键（后台唤起主窗口）前，建议在系统设置 → 快捷键中确认「TerminalBuddy」已被允许
- 启用「终端跟随应用主题」后，切换 UI 主题即可让已有终端实时跟随（未启用则保留每个连接独立配色）
- Web 端与 PC 端的「以此配置新建终端」行为已对齐，跨端启动参数快照一致
