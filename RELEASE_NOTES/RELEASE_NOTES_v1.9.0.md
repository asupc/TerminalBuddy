# TerminalBuddy v1.9.0 功能更新清单

> 发布日期：2026-11-13

本版是 v1.8.0 之后约三周、389 个提交的集中发布：原生 AI 会话的可观测性（思考过程、当前动作、统一状态栏、自动归档）是主线，安卓 App 补齐简版 / 完整版切换、连续发送排队与插话、历史会话恢复和斜杠命令提示，网页版文件导航新增下载能力。同时精简了启动参数预设、机器人通知与 Hook 设置入口，并将 Pi Agent 全面下线、统一收敛为 Claude / Codex。

---

## 🧹 功能精简与设置整理

- **移除启动参数预设**：删除设置入口、连接右键预设菜单、预设管理接口与持久化文件；终端内部仍保留一次性启动参数，项目启动命令与 Claude / Codex 会话恢复不受影响
- **移除机器人通知**：删除飞书、钉钉、企业微信等机器人通道、回调与长连接服务及设置界面；App 通知、原生 AI 会话通知和 Claude Hook 终端决策继续保留
- **移除 Hook 设置入口**：Hook 继续随模型终端自动注入，旧版用户级残留仍在启动时自动清理，不再需要手动选择配置目录或安装、卸载
- **通知立即发送**：等待处理与任务完成通知均移除延迟秒数，事件发生后立即通知；Hook 决策等待时长使用固定服务端上限
- **设置导航调整**：「连接管理」更名为「项目与命令」，项目、连接配置与命令模板集中管理；桌面通知开关迁入「行为设置 → AI 会话」
- **下线 Pi Agent**：移除 Pi 供应商配置、模型启动、会话历史与恢复、扩展与 Hook、RPC 原生会话及安卓端支持，统一收敛为 Claude / Codex 双 Agent，相关配置不再读取

---

## 🧭 状态栏 Agent 信息合并为统一组件

- **一个组件**：原生会话与终端里启动的 Agent 共用同一个状态栏组件，模型、思考强度、上下文占比与本会话 Token 收在同一处展示，不再由多条独立条目拼装
- **上下文告警色**：上下文占用超过 60% 显示黄色、超过 80% 显示红色，不用展开明细也能看出上下文是否吃紧
- **点击查看详情**：点击 Agent 条目从状态栏上方弹出详情浮层，展开模型 / 思考强度 / 供应商 / 数据来源、上下文进度条、本轮与本会话累计 Token 与缓存命中率；终端来源还会显示 transcript 的上次更新时间

---

## 🗂️ Agent 会话按闲置天数自动归档

- **开关与阈值**：「行为设置 → 会话自动归档」可开启自动归档并设置「N 天未使用」阈值（1–3650 天，默认 30 天）；开启或修改阈值时立即按新设置执行一次，并提示实际归档数量
- **归档范围**：同时覆盖 Claude Code 与 Codex 历史会话，以会话最后一次产生内容的时间计算闲置天数；收藏的会话永不自动归档
- **尊重手动操作**：用户手动取消归档后，同一版本不会被下一轮自动归档立刻封回去，只有会话再次更新并重新超过阈值后才再次具备资格
- **执行时机**：服务启动 30 秒后检查一次、之后每 6 小时一次，历史面板扫描补齐索引后也会补跑；归档变化会实时推送给打开着的历史面板与状态栏浮层

---

## 💭 原生会话可见 AI 思考过程与当前动作

- **思考不再被丢弃**：Claude 的 `thinking_delta` 累积为会话级 `thinking` 实时快照，贴在「思考中」状态行下方滚动显示最新一句，点开可看尾部全文，并给出段数与累计字数
- **工具组标题显示当前动作**：折叠组标题跟随最近一次调用的实际动作（如 `Read AgentMessageList.tsx`、`Bash 前端类型检查`），绝对路径按项目根缩成相对路径
- **不打扰的三条边界**：思考不落盘、不进 `messages`、只保留尾部 4000 字（按段落边界截断）
- **安卓同步**：思考面板在手机端同样折叠成一行、点开看全文，窄屏不额外占高

---

## 📱 安卓 App

- **简版 / 完整版切换**：「我的 → 界面模式」可在同一安装包内切换两种界面，共用登录、AI 会话、服务端终端与通知代码，选择保存在本机并立即生效，首次安装默认进入简版
- **简版首页重做**：Tab 精简为「最近会话 / 历史会话」；终端 Agent 会话与存量原生会话按最近活动时间统一平铺，不再按来源分组
- **「开始对话」改为服务端终端**：按所选项目、助手与模型在服务端创建空白终端并注入 Agent 启动命令，手机与电脑是同一个 PTY，任意一端都能继续或交替操作
- **连续发送消息**：新增「发送方式」设置（默认排队发送）；AI 回复期间的消息在服务端排队，App 后台被杀也不丢失；支持原生插话，把消息直接交给运行中的 CLI 进程
- **历史会话浏览与恢复**：新增 `GET /api/ai/history` 与 `POST /api/ai/history/rescan`，Claude / Codex 的转录历史首次对手机端可见，点击即恢复并进入对话
- **服务端任务通知与决策**：新增 `/ws/notifications` 与 `/api/notifications/decisions`，App 重连时补发待决策快照；决策支持单选、多选与自定义回答，提交后由服务端回填原 CLI
- **斜杠命令提示**：解析服务端 `system/init` 下发的 `slashCatalog`，输入 `/` 时展示候选条，命令清单按 Agent 缓存到本机

## 🖥️ 桌面版浏览器直达完整界面

- 桌面版内嵌 Web 服务改为与独立服务端同款布局：电脑浏览器访问 `/` 直接进入与桌面端一致的完整工作界面，`/m/` 为手机版界面，手机 UA 访问 `/` 自动分流并保留查询串
- 完整界面登录页新增「打开手机界面」入口与 `?token=` 免密快捷登录
- `tauri build` 的 beforeBuildCommand 增加 `build:web:desktop`，随桌面端一起构建网页产物

---

## 📁 网页版文件导航支持下载到本机

- **浏览器下载**：Linux 服务端与 Docker 部署的完整网页界面中，文件导航右键新增「下载」，通过浏览器直接保存到本机
- **文件夹打包**：右键文件夹可「下载文件夹（ZIP）」，服务端递归打包后流式返回，自动跳过符号链接
- **流式与清理**：新增 `/api/desktop/download`，沿用项目目录白名单鉴权，ZIP 临时文件在响应结束后自动删除

---

## 🐛 修复

- **原生会话子代理抽屉不再始终为空**：按 `task_type` 剔除后台 Bash 命令误记；兼容 CLI 2.1.x 的 `Agent` 工具新名；补充 `--forward-subagent-text` 转发子代理正文；旧会话按子代理名回落筛选
- **修复 Windows 桌面端关闭 Web 服务时偶发整体崩溃**：改为连接 task 只携带独立 `Watcher`、关停方独占本体，排空等待设 10 秒上限
- **同端口快速「停止→重启」偶发端口占用**：绑定增加 2 秒 `AddrInUse` 重试窗口
- **App 查看服务端终端不再右侧留白**：尺寸计算改用容器实际宽度
- **App 关闭终端后回到终端列表**：关闭成功即清空当前选中终端并刷新列表

---

## 🚚 构建与依赖

- **Windows exe / Android APK 改本机工具链直构**：`xcj/build-windows-exe.sh`（cargo-xwin）与 `xcj/build-android.sh` 在 Linux 本机直接产出，不再依赖 Docker；依赖缺失自动补齐，产物归档到 `dist/` 并附带 `.sha256`
- **依赖分阶段升级**：前端升级 Tauri 2.12、Monaco 0.57、xterm 6.1 beta 与 React 19.3，并用 alias 修补 Monaco 内联 DOMPurify 漏洞；Rust 跨大版本升级 `rusqlite 0.42` 与 `zip 9`；Android 升级 AndroidX 组件与 kotlinx-coroutines

---

## 📌 升级提示

- **Windows 桌面版**：可直接覆盖安装，数据结构无变化
- **Docker / 飞牛部署**：推荐用 `update.sh` 滚动升级，失败自动回退；本版移除了机器人通知配置，相关旧配置不再读取
- **安卓 App**：首次启动默认进入简版界面，可在「我的 → 界面模式」切回完整版；历史会话与连续发送能力需要服务端同步升级到 v1.9.0
