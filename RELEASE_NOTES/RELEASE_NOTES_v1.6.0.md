# TerminalBuddy v1.6.0 功能更新清单

> 发布日期：2026-09-24

---

## 🤖 Claude Code 会话历史

v1.6.0 的核心变更是 Claude Code 会话历史管理：自动索引本机 Claude Code 转录，在 TerminalBuddy 内浏览、检索、回放与一键恢复历史会话。

- **自动索引**：解析 `~/.claude/projects/<路径编码>/*.jsonl` 转录，存入 SQLite（`terminal_buddy.db`）；按文件 mtime / 大小增量扫描，面板打开时刷新 + 启动后台空闲扫描
- **历史面板**：ActivityBar 新增「会话历史」入口，按项目分组、时间倒序；运行中会话（有 sessionId 映射）标「进行中」置顶
- **双击一键恢复**：双击历史会话即启动空白 PowerShell 并注入 `claude --resume <sessionId>`；若该会话已在某终端中运行则直接聚焦该终端，不重复恢复
- **全文检索**：搜索框输入 ≥2 字符可切换全文模式，跨全部历史会话做中文友好的子串匹配；点击命中片段跳转回放视图并锚定到具体消息
- **回放视图**：特殊标签页完整回放对话——user / assistant 正文 Markdown 渲染、工具调用折叠为「工具名 · 入参摘要」；按 seq 分页加载，大转录文件不卡顿
- **导出**：右键导出为 Markdown（对话 + 工具调用摘要）或 JSON（原始转录），走原生保存对话框
- **管理操作**：重命名 / 收藏 / 归档 / 删除（元数据存侧车表，不动 JSONL；删除移入 `<dataPath>/Trash/` 不硬删）

---

## 🧪 默认终端接管（实验功能）

- 设置 → 行为页新增「接管 Windows 默认终端」开关，采用系统 COM 代理方案：注册 `HKCU\Console\%%Startup` 委托值 + LocalServer32 COM 类，Windows 的终端 handoff 直接交给 TerminalBuddy
- **全程仅写 HKCU，无需管理员权限**；开启时自动备份原委托值，关闭时按备份恢复原状（开→关→开→关回到最初值）
- 开关状态以注册表为唯一权威来源，UI 与注册表不一致时自动回滚显示

---

## 🖥️ 界面与设置

- ActivityBar 新增「会话历史」面板入口；回放视图走特殊标签页（与 Git 历史同模式），长文本阅读有完整宽度
- 新增「启动时展开会话历史面板」设置；标题栏按钮可随时切换历史面板显隐

---

## 📚 工程与质量

- SQLite 迁移机制升级为分档迁移（`has_migration`），新增 `claude-history-v1` 迁移自动建 Claude 会话索引表
- 新增会话历史相关后端命令组（列表 / 检索 / 回放 / 导出 / 管理等），全部通过 invoke 覆盖率校验（149/149）
- Rust 单元测试 158/158 通过；`tsc --noEmit` 通过
- JSONL 解析器容错设计（跳过无法解析的行），纯逻辑均入 `#[cfg(test)]` 可测模块

---

## 🔄 兼容性

- **数据存储**：沿用 v1.5.0 的 `%APPDATA%/TerminalBuddy/` 目录结构；新增 `Trash/` 回收站目录与 `terminal_buddy.db` 新表，均自动创建，无需手动迁移
- **Claude Code 数据只读 + 侧车**：索引与回放只读取 JSONL 转录，重命名 / 收藏等元数据写侧车表，不修改 Claude Code 的任何原始文件
- **默认终端开关默认关闭**：不改变系统现有终端行为，需手动开启

---

## 📌 升级建议

- 从 v1.5.0 直接覆盖安装即可，无需先卸载
- 首次打开「会话历史」面板时自动建立索引，历史会话较多时首次扫描需片刻，之后增量刷新
- 如需接管系统默认终端，在 设置 → 行为页 开启实验开关；关闭后系统恢复原默认终端，可放心尝试
