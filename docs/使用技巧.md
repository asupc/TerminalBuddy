# TerminalBuddy 使用技巧

面向日常使用的实用技巧速查，按功能分区。快捷键与操作均以当前版本实现为准。

---

## 快捷键速查

| 快捷键 | 作用 | 生效位置 |
|--------|------|----------|
| `F11` | 专注模式切换：隐藏/恢复所有侧边面板与标签栏 | 全局 |
| `F2` | 重命名：分组、配置文件、标签、本地文件树条目 | 对应面板中选中项时 |
| `Ctrl+F` | 搜索终端输出内容 | 终端聚焦时 |
| `Ctrl+V` | 粘贴文本，或从资源管理器直接粘贴文件路径 | 终端聚焦时 |
| `Ctrl+C` | 复制选中文本（本地文件树中复制路径） | 有选区时 |
| `Ctrl+点击` | 在浏览器中打开 URL | 终端中的链接 |
| 右键 | 粘贴（可在设置中开启"右键粘贴"） | 终端聚焦时 |
| `Esc` | 关闭弹窗 / 取消重命名 | 弹窗、内联编辑 |

> `F2` 会根据"最后点击的区域"决定重命名对象，所以先点一下目标（分组标题、标签、文件），再按 `F2`。

## 配置文件与分组

- **层级分组**：配置文件支持多级分组，用 `GroupCascader` 级联选择器建立层级；分组可递归折叠。
- **配置专属外观**：每个配置可设置独立的终端主题（`colorTheme`）、标签颜色（`tabColor`）和启动窗口尺寸。
- **启动即执行**：在配置中填写 `startupCommands`，终端启动后自动依次执行；配合 `startupPath` 直接进入工作目录。
- **环境变量**：按配置注入 `environmentVariables`，无需在系统层面全局设置。
- **复制配置**：在设置 → 连接管理中可复制现有配置，快速派生相似连接。

## 多终端类型

支持 `powershell` / `pwsh`（PowerShell 7）/ `cmd` / `ssh` / `docker` / `k8s` / `mstsc`。

- 底层统一以 `cmd.exe` 作为 PTY，按类型注入对应命令，因此各类型共享一致的标签、分屏、搜索能力。
- **SSH**：配合远程文件管理器与服务器监控使用（见下）。
- **Docker / K8s**：填好容器/Pod 信息即可一键进入交互 shell。
- **MSTSC**：直接从配置发起远程桌面连接。

---

## 标签页与分屏

- **两种导航形态**：垂直侧边标签栏（`TabNav`）或水平标签栏（`TerminalTabBar`），在设置 → 通用中通过"标签导航"切换。
- **分组标签**：标签可分组管理，支持颜色标签与"呼吸灯"状态提示、拖拽排序。
- **关闭确认**：关闭执行中的终端会弹窗确认，可选择关闭单个 / 分组 / 全部 / 其他 / 左侧 / 右侧。
- **分屏**：在同一标签内做分屏布局，可为分屏终端单独设置字体大小。

---

## 本地文件树

- **书签**：常用目录加书签，快速跳转。
- **拖拽到终端**：把文件从文件树拖入终端，自动粘贴其路径。
- **排除规则**：在设置 → 文件排除中配置，支持精确名称、`*.ext`、`**/*.ext` 三种形式，隐藏噪声文件。
- **内联重命名**：选中条目按 `F2` 直接改名。
- **双击打开编辑器**：双击文本文件用内置 Monaco 编辑器打开为标签页，支持语法高亮、查找替换、格式化。

## Git 图形界面

文件面板内置 Git 工具栏（`GitNavBar`），无需切到命令行即可：

- 查看仓库状态、分支列表与切换、拉取。
- 提交：可全部提交或仅提交选定文件。
- 推送：带预览与选项。
- 历史：SVG 绘制的提交历史图，单文件差异查看。

---

## SSH 远程文件与服务器监控

- **远程文件管理器**：面包屑导航，右键菜单支持上传、下载、重命名、复制、移动、`chmod` 改权限、删除，并显示传输进度。
- **下载目录**：在设置中配置 `sshDownloadDir` 统一下载落点。
- **服务器监控**：实时查看 CPU、内存、交换分区、磁盘、网络速度、运行时间，刷新间隔可在设置中调整（`serverMonitorInterval`）。

---

## 命令补全、模板与历史

- **智能补全**：当前输入行会与模板 + 历史记录做模糊匹配，弹出候选。
- **命令模板**：内置 10 类模板（网络、进程、文件、系统、Git、Docker、Python、Node、.NET、PowerShell），可自定义命令、显示/隐藏、编辑描述。
- **命令历史**：可搜索，支持给命令加备注，导入/导出便于跨机复用。

## 主题与外观

- 8 款内置主题，另可用 16 色 ANSI 主题编辑器自定义。
- 支持深色 / 浅色 / 跟随系统，通过 `<html>` 的 `data-theme` 切换。
- 主题可全局设置，也可在配置文件级别覆盖。

## Web 远程访问

- 在设置 → Web 远程管理中启用内置 HTTP/WebSocket 服务器，浏览器即可远程操作终端，移动端有专用输入栏。
- **功能页面**：Web 端有四个页面——会话（终端列表）、项目与命令（⚡ 一键启动项目，可选用匹配的启动参数预设）、历史（Claude 会话历史浏览 / 全文检索 / 回放 / 一键 resume）、文件（只读项目文件树 + Git 分支切换 / 提交 / 拉取 / 推送）。文件树与 Git 只能访问已登记的项目目录。
- **认证**：JWT + bcrypt 密码哈希，设置用户名与密码。
- **会话隔离**（默认开启，即 `webApiShareSessions=false`）：
  - Web 客户端只能看到/操作 Web 端创建的终端；
  - PC 端能看到 Web 端终端，但不能写入/缩放/关闭；
  - 需要双端共享同一会话时，把 `%APPDATA%/TerminalBuddy/settings.json` 中的 `webApiShareSessions` 改为 `true` 后重启应用（设置页暂无该开关的 UI）。
- Web 端接管桌面终端时允许缩小 PTY 列数以适配窄屏；桌面端视图会随之重排，Web 端断开后自动恢复。

## AI 用量监控

标题栏悬浮面板可查看多家 API 用量：智谱 GLM、百度千帆、DeepSeek、Minimax、火山方舟。在设置 → AI 用量中填入对应的 API Key / Cookie 即可。

## Claude Code 机器人通知

支持飞书、企业微信、钉钉及 QQ/通用桥接：可发送终端截图，并通过"引用回复"完成远程决策。接入步骤见 [机器人通知接入指南](机器人通知接入指南.md)。

## 窗口、托盘与数据

- **启动模式**：可设为普通窗口或最大化启动；支持开机自启。
- **关闭行为**：可选退出或最小化到托盘（`closeBehavior`）；单实例模式避免重复启动。
- **工作区**：保存并恢复整套终端布局（`Workspaces/`）。
- **数据可移植**：所有数据以 JSON 存于 `%APPDATA%/TerminalBuddy/`（`Profiles/`、`Workspaces/`、`command_history.json`、`command_templates.json`、`settings.json`），支持完整导入/导出，也可自定义数据路径迁移。
