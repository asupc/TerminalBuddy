## 二、问题清单（严重 / 高 / 中）

严重度：🔴 严重（数据丢失）、🟠 高、🟡 中。标注【安全】的为边界/授权类。

### 🔴 S-1 编辑器保存等待期继续编辑被误标「已保存」，关闭标签即丢数据

- **位置**：`src/components/text-editor/TextEditor.tsx:374-470`（关键 458 行）；后果落在 `src/components/shell/TabNav.tsx:384`
- **问题**：Ctrl+S 取 `ed.getValue()` 快照后走 await 链（SSH 场景等上传最长 30 秒），最后**无条件** `onDirtyChange(false)` 并把 `lastLoadedContentRef` 置为旧快照；等待期输入的 dirty 标记被覆盖清除，脏点消失。
- **触发**：SSH 文件 Ctrl+S → 上传等待窗口内继续打字 → 上传完成 dirty 被清 → 关标签无确认 → 等待期内容永久丢失。

### 🟠 H-1 `memory_dir_of` 多取一层 parent，Claude Memory 功能整体失效

- **位置**：`src-tauri/src/services/claude_config_service.rs:170`
- **问题**：对 `<projects>/<enc>/<id>.jsonl` 连取两次 `parent()` 得到 `<projects>`，再 join 得 `<projects>/memory`（不存在）；真实 memory 在 `<projects>/<enc>/memory`（本机实证）。Memory 页读写建删全部失效，`list_projects` 的 `has_memory` 徽标恒 false。
- **触发**：打开 Claude 面板 Memory 页 → 永远提示「该项目没有 memory 目录」。

### 🟠 H-2 全局 instances Mutex 临界区内阻塞 PTY 写，单终端堵塞冻结全部终端

- **位置**：`src-tauri/src/commands/terminal.rs:1492-1508`（同模式 870-890、1609-1623）；`web/ws.rs:266-274` 在 async 任务直接同步调用
- **问题**：`write_to_terminal` 持全局唯一实例表锁执行 `write_all`；前台进程不读 stdin 时管道写无限期阻塞，authorize/resize/列表/teardown 全部排队——连关闭肇端自救都不行。
- **触发**：某终端跑不消费 stdin 的进程 → 向其粘贴大块文本 → 所有终端的输入/resize/`GET /api/terminals` 全部挂起。

### 🟠 H-3 Web 端 Git 经「向上回溯找 .git」越过 ensure_project_scope

- **位置**：`src-tauri/src/commands/git.rs:220-233`（discover_git_root）、`:630-645`（repo_root_for_path）、`web/handlers/git_handler.rs:99`
- **问题**：scope 只校验请求传入的路径；随后实现层向上找 `.git` 并以祖先仓库根（含 `rev-parse --show-toplevel` 的外层 worktree 根）为操作根，无二次校验。
- **触发**：登记 monorepo 子目录 → Web 端 `POST /api/git/commit` → 对外层整仓 `add -A` + commit + push，登记目录之外的变更一并提交。

### 🟠 H-4 导入全部数据后，下一次任意保存用旧缓存全量覆盖，导入静默丢失

- **位置**：`src-tauri/src/commands/settings.rs:456-462`；`services/settings_service.rs:22-35,77-88`

### 🟠 H-5 数据目录迁移只复制 4 个子目录，大量用户数据留在旧目录「消失」
