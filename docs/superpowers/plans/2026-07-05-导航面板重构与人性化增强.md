# 导航面板重构与人性化增强 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一次性收敛三个导航面板的命名、补齐对称的右键操作、加入面板宽度持久化 / 终端运行时长 / 配置→选项卡拖拽启动等人性化增强。

**Architecture:** 纯前端的机械重命名 + 多个独立小特性。后端只在 `AppSettings` 加两个宽度字段及对应 save 命令。所有改动落在 `terminal-buddy/` 子目录。

**Tech Stack:** Tauri 2.x、React 18、TypeScript、Zustand、Rust（axum/serde）。CSS 为原生样式表。

## Global Constraints

- 实际代码在 `terminal-buddy/` 子目录（仓库根的 `CLAUDE.md` 已声明）。
- Rust↔TS 序列化一律 `camelCase`（serde `rename_all = "camelCase"`）。
- 前端 UI 文本一律简体中文；代码标识符/API 保持英文。
- 项目**无自动化测试**，每个任务以**手动验证 + 单独 commit**收尾，不用 TDD。
- 提交信息遵循项目规范：`[模块] 描述`，结尾附 `Co-Authored-By: Claude <noreply@anthropic.com>`。
- `Profile`、`TerminalSession` 等数据模型名词不动；`lastClickRegion` 的 `'config' | 'tab'` 枚举值保持不变（store 内部 token，非用户可见，改名收益不抵风险）。
- 三个面板的宽度 clamp 区间：配置/文件 `150–500`，选项卡 `150–400`。

- [ ] **Step 1: 新建 formatDuration 工具**

创建 `src/utils/formatDuration.ts`：

```typescript
/**
 * 把毫秒时长格式化为简短后缀：Xs / Xm / Xh / Xd。
 * < 60s → 秒；< 60m → 分；< 24h → 时；否则 → 天。
 */
export function formatDuration(ms: number): string {
  const s = Math.floor(ms / 1000);
  if (s < 60) return `${s}s`;
  const m = Math.floor(s / 60);
  if (m < 60) return `${m}m`;
  const h = Math.floor(m / 60);
  if (h < 24) return `${h}h`;
  const d = Math.floor(h / 24);
  return `${d}d`;
}
```
