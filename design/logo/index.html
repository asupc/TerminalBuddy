方案 A

方案 B

双窗结伴Companion Panes

两张层叠的终端卡片：后面是同伴（天青色），前面是终端（石板色 + >_）。 既是「buddy 结伴」，也对应应用管理多个会话、标签、工作区的能力。 轮廓简单，16px 下仍是清晰的双层方块。六个方案里最「工具理性」的一个。

方案 C

光标小兽Cursor Critter

整个身体就是你终端里那颗块状光标，切成 8-bit 像素圆角，再挖出两只方眼睛和一个像素笑。 像从命令行里跳出来的吉祥物。像素直角让它在一堆圆角应用图标里一眼可辨—— 风险也在这里：更偏玩具感，适合想把「Buddy」做成 IP 的路线。

方案 D

括号拥抱Bracket Hug

一对加粗的方括号像双臂环抱着中间的光标圆点：括号是代码与终端，环抱是 buddy。 负形干净克制，不卖萌也不冰冷；剪影（两个 C 形夹一个点）在任务栏缩到 16px 依然成立。
