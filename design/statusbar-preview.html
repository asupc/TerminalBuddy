底部状态栏

一行三段

从左到右：身份 → 上下文 → 系统入口
左

会话身份

  • 连接类型：本地、SSH、Docker、K8s、远程桌面、编辑器，hover 显示主机或容器详情。
  • 运行状态：绿色呼吸点表示 Claude / Codex 正在执行任务，灰色为空闲。
  • 会话名：点击切换标签，超长省略；Web 或手机端创建的会话追加来源徽标。
中

工作上下文

  • 当前目录：跟随活动会话的 cd 变化，中间省略，点击复制完整路径。
  • Git：分支、ahead / behind 与未提交变更，点击打开 Git 历史。
  • 分屏（P1）：2×1 / 2×2 指示，点击退出分屏。
右

系统与入口

  • Web 服务：启用时显示端口与绿点，点击打开 Web 管理；浏览器端显示连接状态。
  • 时钟：独立刷新，不触发整页重渲染。
  • 版本：有更新时追加橙色提示点，点击查看更新说明。
