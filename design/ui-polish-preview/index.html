TerminalBuddy UI 美化预览 定时任务 + 设置中心全分区
1. 全站控件与圆角语言统一

将此前混用的 28–36px 高度、2–10px 圆角、两套开关（settings-toggle / tb-switch）统一为 32px 控件基准、6/8/12px 层级圆角与 38×22 胶囊开关，适配所有深浅色与皮肤。

2. 设置剩余子页面全面卡片化

补全 快捷键（键帽样式）、数据管理、SSH、AI 用量（凭据状态卡）、网页认证、文件排除、连接/命令列表的卡片容器；Web 管理改用双栏，消灭 480px 窄栏右侧大片留白。

3. 定时任务主工作区升级

顶部增加调度器状态徽章、4 格微缩指标条与筛选/搜索栏；任务卡片优化信息层级（头像图标 + 状态脉冲 + 元数据标签 + 底部最近运行摘要条），并保留状态栏入口联动。

4. 新建弹窗与运行记录打磨

目标切换升级为双说明卡片（项目终端配置 / AI Agent）；Cron 触发预览升级为时间轴胶囊；运行记录新增 5 项 KPI 卡片与更清晰的状态操作列。
