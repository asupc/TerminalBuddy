# TerminalBuddy 安卓 · 会话页三板块重排设计

> **预览**：`design/sessions-redesign/index.html`，双击用浏览器打开即可。手机内的三个板块、项目折叠、智能体切换、终端启动按钮都可点击，A / B 两个方案带手机深浅色切换。
> **相关源码**：`android/app/src/main/java/com/terminalbuddy/android/ui/AiSessionsScreen.kt`、`AiServerSessionsScreen.kt`、`ServerProjectProfilesDialog.kt`

---

## 1. 现状

`AiSessionsScreen` 现在只有两个板块（`AiSessionsScreen.kt:57`）：

```
最近会话  服务端会话
```

终端入口不在这个页面里：它藏在「快速开始」卡片右上角的「更多」按钮后面（`AiHomeWorkspace.kt:75`），点开是 `ServerProjectProfilesDialog` 弹窗。

三个问题：

| 问题 | 位置 | 表现 |
|---|---|---|
| 终端不可见 | `AiHomeWorkspace.kt:75` → `ServerProjectProfilesDialog.kt` | 要回首页、再点「更多」，才知道服务端有没有终端在跑 |
| 板块只有两个 | `AiSessionsScreen.kt:59` | 会话与服务端是两类信息，终端是完全不同的第三类 |
| 最近会话平铺 | `AiSessionsScreen.kt:140` | 12 段以上没有分组，靠更新时间自己找 |

---

## 2. 三个板块的职责

| 板块 | 回答的问题 | 数据来源 |
|---|---|---|
| **最近** | 我正在做什么 | `ui.sessions`（`AiSession`），按 `updatedAt` 排序 |
| **服务端** | 这个项目做过什么 | `ui.serverHistory`，按「智能体 → 项目 → 会话」组织 |
| **终端** | 服务端此刻有什么在跑 | `ui.terminals` / `ui.profiles` / `ui.projects` |

底部导航保持「快速开始 / 会话 / 我的」不变，三个板块都在「会话」一级页内。

---

## 3. 三种方案

### 方案 A · 静水列表（建议先上）

沿用现有松柏绿配色与卡片语言，把两格标签扩成三格胶囊，其余交给字体和留白。

- 切换：顶部三格胶囊，分别带会话数、项目数、已打开终端数
- 最近：按「今天 / 更早」分组；运行中会话带底色 + 状态标签
- 服务端：智能体下划线标签 → 项目折叠卡 → 会话行
- 终端：「已打开」横向卡片 + 「项目配置」列表，启动按钮原地变成「已打开」

改动量最小，组件几乎全部复用，风险最低。代价是三个板块仍需切换，终端比会话多一步。

### 方案 B · 三栏工作台

不再切换，把整页当一块工作台，三段依次铺开。

- 概览：三枚数字（运行中 / 未读 / 已打开终端）
- 最近：横向吸附卡片，露出下一张
- 服务端：智能体 + 项目两级切片（chip）
- 终端：两列深色瓦片，与浅色会话区形成对比

一屏能看到三类信息，适合把服务端状态放第一位的工作流。代价是首屏信息偏满，必须滚动才能看全。

### 方案 C · 终端视野

把会话页写成终端该有的样子：等宽字、点线引导、树状结构。

- 标签：`[1] 最近` `[2] 服务端` `[3] 终端`
- 最近：标题与时间之间用点线引导，状态写成 `[运行中]`
- 服务端：`terminal-buddy/` 树状缩进，`├─` `└─` 表达层级
- 终端：已打开是进程表，配置是 `$` 开头的启动命令

页面固定深色，强调色只用一处薄荷绿。阅读门槛与中文等宽排版成本最高，建议先在「纯黑」皮肤内小范围验证。

---

## 4. 对照

| 维度 | A · 静水列表 | B · 三栏工作台 | C · 终端视野 |
|---|---|---|---|
| 切换方式 | 顶部三格胶囊 | 不切换 | 终端式编号标签 |
| 三板块同屏 | 否 | 是 | 否 |
| 首屏重点 | 最近会话 | 运行状态 | 最近会话 |
| 信息密度 | 中 | 高 | 高 |
| 视觉语言 | 现有松柏绿 | 弥散浅色 + 深色瓦片 | 纯黑 + 等宽中文 |
| 改动成本 | 低 | 中 | 高 |
| 主要风险 | 终端仍多一步 | 首屏信息偏满 | 阅读门槛较高 |
| 建议 | **先上** | 备选迭代 | 小范围验证 |

---

## 5. 落地范围

| 文件 | 改动 |
|---|---|
| `AiSessionsScreen.kt` | 2 页 pager 扩成 3 页（A/C）；B 改为同页分段 + 概览 |
| `AiServerSessionsScreen.kt` | 服务端板块原样迁入，保留「筛选独立于快速开始配置」的现有行为 |
| `ServerProjectProfilesDialog.kt` | 终端板块复用 projects / profiles / terminals；弹窗保留给快速开始 |
| `ServerTerminalViewModel.kt` | 已打开终端、启动与连接状态，三案共用 |
| `AiNavigation.kt` | 底部导航不变；B 若采用需新增概览统计状态 |

三个方案共用同一份数据，区别只在版式与切换方式。终端板块直接复用现有项目配置弹窗的状态，不再单独维护一份。
